Kizamia Unified API

Версия 1.0.0 · все методы возвращают Promise · хранилище: localStorage + IndexedDB

API подключается одним файлом js/kizamia-api.js и доступен глобально как KizamiaAPI. Подходит для любых будущих проектов без сборщиков и зависимостей. 

<script src="js/kizamia-api.js"></script>
<script>
  // Пример: создать заметку
  const note = await KizamiaAPI.Notes.create({
    title: 'Идея',
    body: 'Сделать что-то полезное'
  });
</script>

📖 Reader

KizamiaAPI.Reader.saveBook({ id, name, type, arrayBuffer, progress })
Сохраняет книгу в IndexedDB. Возвращает запись книги.
KizamiaAPI.Reader.getAllBooks()
Возвращает все книги, отсортированные по дате добавления (новые сверху).
KizamiaAPI.Reader.updateProgress(id, progress)
Обновляет прогресс чтения (0–100).
KizamiaAPI.Reader.setBookmark(bookId, page) / getBookmark(bookId)
Сохраняет и читает закладку для книги.

🚀 TroubleTab

KizamiaAPI.TroubleTab.getTabs()
Возвращает массив вкладок. По умолчанию — 4 поисковика.
KizamiaAPI.TroubleTab.addTab({ title, url, icon })
Добавляет новую вкладку и сохраняет в localStorage.
KizamiaAPI.TroubleTab.removeTab(index)
Удаляет вкладку по индексу.

📝 Notes

KizamiaAPI.Notes.create({ title, body, type, folder, color })
Создаёт заметку. type: text | list | template | diary.
KizamiaAPI.Notes.update(id, patch)
Обновляет поля заметки. Автоматически обновляет updatedAt.
KizamiaAPI.Notes.getBacklinks(noteTitle)
Возвращает заметки, содержащие [[noteTitle]] в теле.

🖼️ Upscale

KizamiaAPI.Upscale.upscaleImage(file, scale = 2)
Апскейлит изображение через OffscreenCanvas. Возвращает { blob, width, height }. Для продакшена можно заменить на Web Worker + нейросетевую модель.
KizamiaAPI.Upscale.saveResult({ id, originalName, width, height, scale, blob })
Сохраняет результат апскейла в IndexedDB.

⚙️ Общие методы

KizamiaAPI.exportAll()
Возвращает JSON со всеми данными (localStorage + IndexedDB) для бэкапа.
KizamiaAPI.clearAll()
Полностью очищает localStorage и IndexedDB. Использовать с осторожностью.
