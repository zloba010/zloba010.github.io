📖 Kizami Free Web Reader

Готово

Полноценная читалка в браузере. Поддерживает TXT, FB2, EPUB и PDF. Прогресс и библиотека хранятся в IndexedDB и localStorage — данные не покидают устройство.

Ключевые функции
  • Библиотека книг без регистрации
  • Продолжение с последнего места
  • Закладки
  • Чтение вслух (системные голоса + Piper офлайн)
Технологии
  • IndexedDB (книги, файлы)
  • localStorage (прогресс, закладки)
  • Web Speech API
  • Piper TTS (опционально)
API-модуль: KizamiaAPI.Reader.saveBook(), getAllBooks(), updateProgress()

🚀 TroubleTab — экспресс-панель

Готово

Кастомная новая вкладка браузера: быстрый доступ к поисковикам, погоде, сервисам Kizamia. Все настройки хранятся локально.

Ключевые функции
  • Поисковики (Google, Yandex, DuckDuckGo, Bing)
  • Погода и приветствие по времени суток
  • Добавление своих вкладок с иконками
  • Быстрые ссылки на другие сервисы
Технологии
  • localStorage (вкладки, настройки)
  • Fetch API (погода)
  • Чистый JS / CSS
API-модуль: KizamiaAPI.TroubleTab.getTabs(), addTab(), getWeatherConfig()

📝 Kizamia Notes

Готово

Быстрые заметки с папками, списками, шаблонами и дневником. Поддерживает обратные ссылки, закрепление, цвета и озвучивание.

Ключевые функции
  • Текст, списки, шаблоны, дневник
  • Папки и перемещение заметок
  • Обратные ссылки [[Заметка]]
  • Закрепление и цветовые метки
  • TTS-озвучка заметок
Технологии
  • localStorage (все заметки)
  • Web Speech API
  • Чистый JS / CSS
API-модуль: KizamiaAPI.Notes.create(), update(), getBacklinks()

🖼️ Kizamia Upscale Image

Готово

Полностью офлайн-апскейл изображений. Файл не покидает устройство. Поддерживает PNG, JPG, WEBP, BMP, GIF, AVIF. Есть сравнение «до/после».

Ключевые функции
  • Drag & drop + вставка из буфера
  • Сравнение до/после
  • Без лимита итогового разрешения
  • Работает без интернета
Технологии
  • Canvas / OffscreenCanvas
  • Web Workers (для тяжёлых изображений)
  • IndexedDB (кэш результатов)
API-модуль: KizamiaAPI.Upscale.upscaleImage(), saveResult(), getAllResults()

Kizamia Unified API

Версия 1.1.0 · методы возвращают Promise или значение · хранилище: localStorage + IndexedDB

API встроен в этот файл и доступен глобально как KizamiaAPI.

📖 Reader

KizamiaAPI.Reader.saveBook({ id, name, type, arrayBuffer, progress })
Сохраняет книгу в IndexedDB.
KizamiaAPI.Reader.getAllBooks()
Все книги, отсортированные по дате добавления.
KizamiaAPI.Reader.updateProgress(id, progress)
Обновляет прогресс (0–100).
KizamiaAPI.Reader.setBookmark(bookId, page) / getBookmark(bookId)
Закладки.

🚀 TroubleTab

KizamiaAPI.TroubleTab.getTabs()
Возвращает массив вкладок (по умолчанию 4 поисковика).
KizamiaAPI.TroubleTab.addTab({ title, url, icon })
Добавляет вкладку.
KizamiaAPI.TroubleTab.removeTab(index)
Удаляет вкладку по индексу.

📝 Notes

KizamiaAPI.Notes.create({ title, body, type, folder, color })
Создаёт заметку. type: text | list | template | diary.
KizamiaAPI.Notes.update(id, patch)
Обновляет поля.
KizamiaAPI.Notes.getBacklinks(noteTitle)
Заметки с [[noteTitle]].

🖼️ Upscale

KizamiaAPI.Upscale.upscaleImage(file, scale = 2)
Апскейл через OffscreenCanvas. Возвращает { blob, width, height }.
KizamiaAPI.Upscale.saveResult({ id, originalName, width, height, scale, blob })
Сохраняет результат в IndexedDB.
